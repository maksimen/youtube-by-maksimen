# YouTube by maksimen

Android-проект: оболочка для запуска VPNUS и YouTube ReVanced.

## Что делает первая версия
- Проверяет наличие активного системного VPN.
- Если VPN уже активен — запускает `com.google.android.youtube`.
- Если VPN не активен — открывает VPNUS (`io.nimbusnet.app`).
- После возврата в Hub повторно проверяет VPN и запускает YouTube, если VPN активен.

**Важно:** Android может не вернуть пользователя в Hub автоматически после подключения VPNUS. В первой версии, если VPNUS просто подключился и остался на экране, нужно вручную вернуться в Hub. Приложение не управляет внутренней кнопкой подключения VPNUS и не гарантирует восстановление подписки. Оно только проверяет системный факт VPN-подключения.

## Сборка APK через GitHub (можно с телефона)
1. Создайте новый пустой репозиторий на https://github.com/new, например `youtube-by-maksimen`.
2. Распакуйте ZIP на телефоне или компьютере.
3. Загрузите **содержимое** папки проекта в корень репозитория (включая скрытую папку `.github`).
4. Откройте вкладку **Actions** репозитория.
5. Если GitHub попросит, нажмите **I understand my workflows, go ahead and enable them**.
6. Выберите **Build Android APK** → **Run workflow**.
7. Дождитесь зелёной галочки, откройте завершённый запуск и скачайте artifact `YouTube-by-maksimen-debug`.
8. Распакуйте скачанный artifact ZIP — внутри будет `app-debug.apk`.

Также сборка запускается автоматически при каждом push в ветку `main`.

## Требования
- Android SDK Platform 35 устанавливается GitHub runner-ом через Gradle Android Plugin.
- Java 17.
- Gradle 8.11.1.

Это debug APK для личного тестирования, не релизная подписанная сборка для Google Play.
